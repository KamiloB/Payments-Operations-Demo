🌎 English
> Extracted from a real-world SaaS system.

### What this is

A standalone payments operations demo covering payment registration, status tracking, receipt generation, and WhatsApp follow-up.

---

### Problem it solves

Operations teams need a fast way to register payments, verify current validity, and communicate proof of payment without switching systems.

---

### What you can do in this demo

- Register new payments
- View payment history per student
- Check whether a payment is active or expired
- Generate receipt images
- Contact the client via WhatsApp with a prefilled message

---

### What it includes

- Grouped payment history per student.
- Active vs expired status logic based on validity dates.
- New payment flow with controlled form inputs.
- Receipt modal with image export (`html2canvas`).
- WhatsApp integration with dynamic, contextual message payload.

---

### How to run

- npm install
- npm run dev
